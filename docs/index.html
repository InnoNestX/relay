Principles核心原则

  1. The supervisor dispatches, never executes.主管只调度,不亲自执行。
  2. One owner per external write channel — chat, defect system, knowledge base, code/deploy.一类外部写操作只有一个出口——IM、缺陷系统、知识库、代码/部署。
  3. Judge against the latest requirement — pass, file, or escalate.按最新需求判定——符合即过、不符合提单、拿不准升级。
  4. Conclusions live in an online report; issue numbers stay in sync in three places.结论进在线报告;编号三处同步。
  5. Testing never queues — scale out parallel helpers; testers make their own data.测试不排队——并行拉临时助手;测试自己造数。
  6. Security red lines override everything.安全红线高于一切。
  7. Every delivery passes the scoring gate.每次交付都过打分门禁。
