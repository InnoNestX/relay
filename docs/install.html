Install安装

Pick your tool选择你的工具

Claude Code and ClawHub have real plugin packages. Everything else uses the same recipe: paste the system prompt, then optionally add the MCP server.Claude Code 与 ClawHub 有正式插件包。其余工具用同一套:贴上系统提示,再按需接 MCP 服务。

Claude Code Cursor ChatGPT Gemini Grok ClawHub Docker / local MCP (any client)

Claude Code

A real plugin: slash commands + the 24 skills.正式插件:slash 命令 + 24 个技能。

/plugin marketplace add InnoNestX/relay
/plugin install relay@relay

Then run /relay-start <requirement> to act as the supervisor, or /relay-score to run the gate.然后用 /relay-start <需求> 以主管身份启动,或 /relay-score 跑门禁。

Cursor

  1. Copy plugins/cursor/relay.mdc into your repo's .cursor/rules/.把 plugins/cursor/relay.mdc 放进仓库的 .cursor/rules/。
  2. Add the MCP server to .cursor/mcp.json (see below), or copy plugins/cursor/mcp.json.把 MCP 服务加到 .cursor/mcp.json(见下),或复制 plugins/cursor/mcp.json。

ChatGPT / GPT

  1. Create a Custom GPT (Explore GPTs → Create).新建一个自定义 GPT(Explore GPTs → Create)。
  2. Instructions: paste plugins/system-prompt.md.Instructions:粘贴 plugins/system-prompt.md。
  3. Knowledge: upload the skills/*/SKILL.md files + templates/scorecard.md.Knowledge:上传 skills/*/SKILL.md + templates/scorecard.md。
  4. Or, if your plan has MCP connectors, add the server below.或者,若套餐支持 MCP 连接器,添加下面的服务。

Google Gemini

  1. Gem: paste plugins/system-prompt.md as the Gem instructions; attach the skills as knowledge.Gem:把 plugins/system-prompt.md 作为 Gem 指令;技能作为知识附上。
  2. Gemini CLI: add the MCP server to ~/.gemini/settings.json (see below).Gemini CLI:把 MCP 服务加到 ~/.gemini/settings.json(见下)。

Grok (xAI)

  1. Paste plugins/system-prompt.md into Grok's custom instructions / workspace.把 plugins/system-prompt.md 贴进 Grok 的自定义指令 / 工作区。
  2. For the full skills, add the MCP server (API / MCP-capable client) or attach the skills/ files.要用完整技能,接 MCP 服务(API / 支持 MCP 的客户端)或附上 skills/ 文件。

ClawHub

clawhub install relay              # skill
clawhub package explore relay      # plugin (OpenClaw package)

Docker / local本地

docker run --rm xuxuclassmate/relay:0.3.2:2797f8315a11acd598949ea63dceaf35c2ce63451168ba6261a1e0e3a8f109a5 list     # list the 24 skills
docker run --rm xuxuclassmate/relay:0.3.2:2797f8315a11acd598949ea63dceaf35c2ce63451168ba6261a1e0e3a8f109a5 score    # print the scoring gate
docker run -i --rm xuxuclassmate/relay:0.3.2:2797f8315a11acd598949ea63dceaf35c2ce63451168ba6261a1e0e3a8f109a5       # run as an MCP server (stdio)

# or from a clone:
node server/cli.mjs list
node server/index.mjs

MCP — any clientMCP — 任意客户端

Add this to your client's MCP config (Claude Code, Cursor, Gemini CLI, ChatGPT connectors, …):把这段加进你客户端的 MCP 配置(Claude Code、Cursor、Gemini CLI、ChatGPT 连接器等):

{ "mcpServers": { "relay": {
    "command": "docker", "args": ["run","-i","--rm","xuxuclassmate/relay:0.3.2:2797f8315a11acd598949ea63dceaf35c2ce63451168ba6261a1e0e3a8f109a5"] } } }

Tools: relay_list_skills, relay_get_skill, relay_get_file, relay_scorecard.工具:relay_list_skills、relay_get_skill、relay_get_file、relay_scorecard。

Every integration is also in the repo under plugins/. Replace each {placeholder} with your own systems before use — never put credentials in the placeholder file.每种接入件也在仓库 plugins/ 下。使用前把每个 {占位符} 换成你自己的系统——占位文件里绝不填凭证。
